#### Highlights & Notes

> 通常必要としないであろう大量の追加パッケージが含まれており、イメージサイズも約1GBほどに膨れ上がっています。もちろんその分、イメージが含んでいる脆弱性の数も増えてしまいます。

> 多くの場合あまり問題になることはないかもしれませんが、クリティカルなプロダクション用途の場合には思わぬバグの元とならないよう、注意が必要です。
