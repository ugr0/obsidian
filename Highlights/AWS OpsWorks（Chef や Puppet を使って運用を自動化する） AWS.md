#### Summary
AWS OpsWorks is a configuration management service that allows users to utilize managed instances of Chef or Puppet. These automation platforms enable the automation of server configuration using code.

#### Highlights & Notes

> AWS OpsWorks は、Chef や Puppet のマネージド型インスタンスを利用できるようになる構成管理サービスです。Chef や Puppet は、コードを使用してサーバーの構成を自動化できるようにするためのオートメーションプラットフォームです。
