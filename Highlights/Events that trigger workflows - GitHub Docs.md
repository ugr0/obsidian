#### Highlights & Notes

> アクティビティ タイプが指定されていない場合、プル リクエストが開かれるか再度開かれるとき、またはプル リクエストのヘッド ブランチが更新されるときにワークフローが実行されます。

> プル リクエストからコードをビルドまたは実行する必要がある場合は、このイベントの使用を避けてください。
