#### Highlights & Notes

> Application Default Credentials (以下 ADC) とはアプリケーションが Google Cloud 上のリソースにアクセスする際のクライアント認証情報を取得するための仕組みです。

> ADC を使用することで、アプリケーションが Google Cloud のサービスや API にアクセスするために必要な認証情報を自動的に取得できます。
