#### Highlights & Notes

> サーバー コンポーネントがない場合、エフェクトを使用してクライアントで静的データを取得するのが一般的です。

> サーバーコンポーネントはビルド時に実行され、ファイルシステムからの読み取りや静的コンテンツの取得を行うため、Webサーバーは必要ありません。

> サーバーコンポーネントは、async/await を用いたコンポーネント記述の新しい方法を導入します。await非同期コンポーネント内では、React はレンダリングを再開する前に、Promise が解決されるまで一時停止し、待機します。これは、サスペンスのストリーミングサポートにより、サーバー/クライアントの境界を越えて機能します。
