#### Highlights & Notes

> max_tokens で縛ると回答が途中で切れてしまうのでプロンプトで指示しています。

> この値を大きくするとより多くの user と assistant の会話履歴を入力プロンプトに含める事ができます。

> QUERY_LIMIT を大きくしすぎるとトークン長が長くなりすぎエラーとなるので注意が必要です。

> 秘匿情報は AWS Systems Manager Parameter Store に登録して隠蔽します。
